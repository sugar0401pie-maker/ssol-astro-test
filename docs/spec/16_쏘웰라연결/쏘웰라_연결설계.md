# 쏠 아스트로 하우스 → 쏘웰라 연결 설계 v1 (2026-10-10)

리포트 끝의 [쏘웰라와 대화 시작하기]를 누르면 쏘웰라 채팅(GPT-6 Luna)으로 넘어간다. 쏘웰라는 별 리포트의 내용을 알고 대화를 시작하되, 새로 점을 보거나 계산하지 않는다.

## 1. 넘기는 흐름

1. 결제 완료 → 서버가 `wellness_results`에 한 줄 쓴다(`test_key='astro'`, `schema_version='astro_handoff_v1'`, `summary` = handoff JSON). 무료만 본 사용자는 `is_paid=false`, 무료 구간 값만 넣는다.
2. 같은 때 `sowella_passes`에 3일 이용권을 만든다(`ends_at = 결제 시각 + 3일`).
3. 버튼을 누르면 쏘웰라는 `wellness_results`에서 이 사용자의 가장 최근 astro 결과를 읽어 대화 맥락에 넣는다. 다른 테스트 결과도 같은 테이블에 있어 나중에 함께 쓸 수 있다.
4. 첫 메시지는 AI가 아니라 DB 문장(B15)으로 바로 보낸다. 토큰은 handoff 값으로 채운다.
5. 3일이 지나면 이용권이 만료되고, 결과는 계정에 남는다.

## 2. handoff JSON (예시: handoff_example.json)

| 묶음 | 내용 | 비고 |
| --- | --- | --- |
| user | 닉네임, 정확도 등급, soft_tone | soft_tone = 2026 단어가 이별·고생·그만하자 |
| answers | Q1 고민 영역, Q2 2026 단어, Q3 2027 바람 | |
| chart_summary | 태양·달·상승궁 별자리, 가장 강한 원소, 기질, 유형(역량·방식·한 줄) | 행성 각도·숫자는 넣지 않음 |
| year_2026 | 하늘 주제(A12t), 어울림/엇갈림, 전환점 2개 | |
| year_end | 조심할 세 가지 제목, 기대해도 좋은 일 | 유료 |
| year_2027 | 키워드, 판정(이중 표기), 움직임, 흐름 단계, 놓아줄 것·키울 것 | 유료 |
| five_years | 연도별 판정·경계·움직임·테마, first_open_year | 유료 |
| questions / practices | 별이 주는 질문 3개, 작은 실천 3개(ssol_id) | 유료. practices는 기존 실천 DB와 같은 ID |
| section_summaries | 섹션별 굵은 요약(B11) | |
| greeting_id | 서버가 고른 B15 첫 인사 ID | |

넣지 않는 것: 출생 시각·출생지·좌표, 결제 정보, 엔진 원본 숫자, AI 원문 전체(요약만). 쏘웰라에 필요한 것은 "무엇을 느끼고 무엇을 하려는 사람인가"이지 출생 데이터가 아니다.

## 3. 쏘웰라 시스템 프롬프트에 덧붙일 부분 (astro 맥락 모드)

```
[별 리포트에서 온 대화]
사용자는 방금 쏠 아스트로 하우스의 별 리포트를 읽고 왔습니다. 아래 <리포트>는 그 요약입니다.

지킬 것
1. 리포트 내용을 근거로 대화하되, 새 점성술 해석·예측·날짜를 만들지 않습니다. 리포트에 없는 행성·연도·사건을 말하지 않습니다.
2. 판정 이름은 리포트 그대로 씁니다(예: "내 손에 달린 해(보통)"). 좋게 바꾸거나 무섭게 바꾸지 않습니다.
3. 별 이야기는 대화를 여는 재료입니다. 대화의 중심은 사용자의 지금 마음과 고민({q1_domain})입니다.
4. 리포트의 '별이 주는 질문'과 '작은 실천'을 한 번에 하나씩, 사용자가 원할 때 꺼냅니다. 실천은 practices의 것을 먼저 쓰고, 새 실천은 기존 실천 DB 규칙대로 고릅니다.
5. soft_tone이 true면 무엇을 정하게 하지 말고 먼저 들어 줍니다. 위기 신호가 보이면 쏘웰라의 기존 안전 규칙을 그대로 따릅니다.
6. 점성술은 자기 성찰을 위한 이야기라는 점을 잊지 않습니다. 운명·확정 표현, 건강·투자·관계 결정 권유는 하지 않습니다.
7. 말투는 쏘웰라 기본 말투에 별 이야기를 살짝 얹습니다(밤하늘·별빛 같은 표현은 대화당 한두 번, 이모지는 첫 인사에만).

<리포트>
{handoff JSON}
</리포트>
```

## 4. 첫 인사 (B15, 8개 — 엑셀·JSON에 있음)

고르는 순서: 재방문이면 RETURN, 이용권 마지막 날이면 LASTDAY → 아니면 SOFT > HEAD > OPEN > NOTIME > QUESTION > DEFAULT 가운데 먼저 맞는 것.

| ID | 조건 | 첫 인사 |
| --- | --- | --- |
| GREET_DEFAULT | 기본 | {닉네임}님, 반가워요! 🌙 별 리포트 잘 읽어 봤어요. {태양별자리}의 빛을 품은 {닉네임}님이 요즘 어떤 마음인지 궁금해요. 리포트에서 마음에 걸린 문장 하나만 골라 와 줄래요? 거기서부터 같이 천천히 이야기해 봐요. |
| GREET_QUESTION | 질문으로 시작 | {닉네임}님, 어서 와요 ✨ 리포트 마지막에 별이 건넨 질문 기억나요? “{질문1}” 오늘은 이 질문을 같이 굴려 봐도 좋고, 전혀 다른 이야기를 꺼내도 괜찮아요. 어디서 시작하고 싶어요? |
| GREET_OPEN | 2027 활짝 열리는 해 | {닉네임}님, 반가워요! 리포트에서 {바람:이/가} 활짝 열리는 해라는 이야기를 봤어요 ✨ 설레는 마음이 들었을까요, 아니면 조금 실감이 안 났을까요? 그 문을 어떻게 열고 싶은지 같이 그려 봐요. |
| GREET_HEAD | 2027 기반을 다지는 해 | {닉네임}님, 와 줘서 고마워요 🌙 리포트에 {바람:을/를} 바로 얻기보다 기반을 다지는 해라는 말이 있었죠. 읽으면서 어떤 마음이 들었는지 먼저 듣고 싶어요. 무거웠다면 무거웠다고 말해도 괜찮아요. |
| GREET_SOFT | 2026 단어 이별·고생·그만하자 | {닉네임}님, 여기까지 와 줘서 고마워요. 올해를 ‘{단어}’(이)라고 고른 마음이 오래 남았어요. 오늘은 무언가를 정하지 않아도 돼요. 지금 가장 마음에 걸려 있는 것부터 편하게 꺼내 주세요 🌙 |
| GREET_NOTIME | 태어난 시간 모름 | {닉네임}님, 반가워요! ✨ 태어난 시간을 몰라도 별은 충분히 많은 이야기를 해 줬어요. 리포트 중에서 “이건 정말 나 같다” 싶었던 부분이 있었어요? 거기서부터 시작해 봐요. |
| GREET_RETURN | 다시 들어왔을 때 | {닉네임}님, 또 만나서 반가워요 🌙 지난번에 “{지난대화요약}” 이야기를 나눴죠. 그 뒤로 마음은 좀 어땠어요? 이어서 해도 좋고, 새로운 이야기도 좋아요. |
| GREET_LASTDAY | 이용권 마지막 날 | {닉네임}님, 오늘이 함께하는 마지막 날이에요 ✨ 리포트의 작은 실천 중에 해 본 게 있어요? 해 보지 못했어도 괜찮아요. 오늘은 앞으로 혼자서도 이어 갈 수 있는 것 하나를 같이 골라 봐요. |

- GREET_SOFT의 ‘{단어}’(이)라고는 서버 조사 함수로 받침에 맞춰 바꾼다(‘이별’이라고 / ‘고생’이라고 / ‘그만하자’라고).
- GREET_HEAD와 GREET_SOFT가 함께 맞으면 SOFT가 먼저다(무거운 날에는 판정보다 마음이 먼저).
- 이모지는 첫 인사 한 번에 하나만. 이후 대화에서는 쓰지 않는다.
