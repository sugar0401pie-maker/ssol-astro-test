## 3. 결과 화면 순서와 요소

1. **{닉네임}님이 태어난 순간의 하늘** — 출생차트 휠(4장), 4원소 막대, 정확도 등급, • 나의 행성 읽기(수성~명왕성 8개: 별자리 + 하우스 문장, B1·B2), • 행성끼리의 관계(주요 각도 3개, B3) — 모두 무료
2. **별이 본 나의 유형** — "양자리 · 별이 본 {닉네임}님은 누군가에게 기대는 일에 에너지가 많이 들고, 그럴 때 먼저 다가가는 유형(기대기 × 다가가기)입니다." + 설명 문단 → 태양·달·상승궁 표(설명이 끝난 뒤). 당분간 캐릭터 이름·일러스트는 쓰지 않는다(show_character=false)
3. **2026년, 나의 한 해** — 굵은 요약 → 공감 문단 → 올해의 전환점 → Q2 마무리 문장 → 분기별 표 → 접힌 근거(표 아래에는 본문 없음)
4. **연말까지 조심하면 좋을 것** (결제 후 열람) — 굵은 요약 → 조심할 세 가지 → 연말에 기대해도 좋은 일(줄글, 구체적으로) → • 달마다 살펴볼 것(• 10월 / • 11월 / • 12월 줄글, 표 없음) → 접힌 근거
5. **2027년을 맞는 마음가짐** (결제 후 열람) — 굵은 요약 → 키워드 문단(2줄 + 기회·주의) → 솔직한 판정(경계·움직임) → 놓아줄 것·키울 것 → • 2027년 흐름(도식·칩 없이 단계별 불릿 문단, “2027년에는 새로 판을 벌이기보다…”로 시작할 수 있음) → 분기별 표 → 접힌 근거
6. **앞으로 5년, {닉네임}님의 삶은 이렇게 흘러갈 거예요** (결제 후 열람) — 굵은 요약 → 열리는 해와 이유 → 기반을 다지는 해(역풍) 솔직하게 → 큰 그림 → 연도별 타임라인 → 접힌 근거
7. **별이 주는 질문과 웰니스 제안** (결제 후 열람) — 굵은 요약 → 질문과 그 이유 → 질문 3개 → 작은 실천 3가지 → 쏘웰라 대화 시작 버튼

## 4. 출생차트 휠

결과 화면 맨 위. 지름 = 화면 폭 − 32px(최대 360px), 인라인 SVG, 배경 투명(밤 배경 위).

| 층(바깥 → 안) | 내용 | 디자인 |
| --- | --- | --- |
| ① 별자리 고리 | 12칸, 칸마다 별자리 기호 | 폭 28px, pearl-gold 0.75px 경계선, cream 기호. 내 태양 별자리 칸만 pearl-gold 12% 채움 |
| ② 하우스 고리 | 1~12 번호 | 홀사인이라 경계가 ①과 같다. 번호 9px, cream 60% |
| ③ ASC·MC 축 | 상승궁(9시 방향), 천정(위) | ASC는 굵은 pearl-gold 선 + 작은 "ASC" 라벨 |
| ④ 행성 | 태양~명왕성 10개 | 지름 22px 원(태양·달 26px) + cream 기호. 4° 안으로 겹치면 바깥으로 밀고 실제 위치까지 짧은 선 |
| ⑤ 각도 선 | 행성 사이 주요 각도 | 점수 상위 8개. 조화 = pearl-gold 실선, 긴장 = cream 점선. "모든 선 보기" 토글 |
| ⑥ 가운데 | 태양 별자리 기호(44px 원 안) — 캐릭터를 켜면(show_character=true) 캐릭터 얼굴 원형 아이콘 | navy 원 테두리 |

- 회전: A·B등급은 ASC를 9시 방향에 둔다. C등급(시간 모름)은 ②·③을 숨기고 양자리 시작점을 9시에 두며 "태어난 시간을 알면 더 정확해져요" 안내 + 시간 추가 버튼.
- 탭: 행성·별자리 칸·선을 누르면 아래 시트에 "달 · 처녀자리 · 4하우스" + 해석(모두 DB). 모든 행성·각도 설명이 무료이고, 같은 내용이 결과 본문 '나의 행성 읽기'에도 나온다(2026-10-09 결정).
- 처음인 사용자: 첫 진입 때 3단계 안내 말풍선(바깥 고리 = 별자리, 동그라미 = 행성, 선 = 행성끼리의 관계).
- 접근성: 휠 아래 접이식 표(행성 / 별자리 / 하우스)로 같은 정보를 글로 제공.
- 공유 이미지: 선을 뺀 단순판(고리 + 행성 기호 + 가운데 태양 별자리 기호) + 유형 문구.

## 5. 캐릭터 일러스트 (당분간 사용하지 않음 — show_character=true일 때만)

- 관계성 테스트의 캐릭터 20종(5역량 × 4방식)을 그대로 쓰되, **밤하늘 아래 장면으로 새로 그린 일러스트**를 쓴다. 생성 프롬프트는 03_캐릭터이미지프롬프트.json.
- 규격: 세로 4:5(1024×1280), 테두리·글자 없음, 화면에서 둥근 모서리(16px)로 잘라 보여준다. 같은 이미지에서 얼굴을 원형으로 잘라 휠 가운데 아이콘(44px)과 공유 이미지에 쓴다.
- 장면 원칙: 화면 위쪽 55~65%는 별이 아주 많은 밤하늘, 지평선은 아래 1/3, 그 아래 캐릭터의 자리(잔잔한 물·바위·모래). 물은 별과 달을 비추는 거울처럼 잔잔하게(파도·물보라 없음). 초승달·반달 하나까지 가능, 보름달은 쓰지 않는다.
- 캐릭터 불변 규칙: 원래 얼굴·몸 색(밤이어도 어둡게 칠하지 않음, 달빛을 받은 원래 색)·둥근 비율·점 눈·일자 입. 옷·모자·별 무늬 추가 금지, 표정은 바꾸지 않고 몸짓으로 분위기 표현.
- 금지: 낮 하늘·노을·해 / 실제 별자리 모양이나 별자리·행성 기호(캐릭터는 모든 별자리 공용이라 어긋남) / 수정구·촛불·망토 같은 점술 소품 / 글자·숫자·로고.

- 접힌 근거는 각 섹션의 **맨 끝**에 "▸ 왜 그럴까 — 하늘에서 일어나는 일"로 두고, 행(시기)마다 따로 접혀 있다가 누르면 열린다.
- 열린 내용 = 이벤트 이름과 날짜 + 그 뜻 한 줄(예: "목성이 화성·태양·수성과 삼분 — 확장의 별이 자연스럽게 돕는 각도로 행동·자아·생각을 밀어 줌"). 뜻 한 줄은 DB(행성·각도·하우스 용어 사전, 05_DB목록 A16)에서 조립한다.
- 특정 날짜가 중요한 이벤트(예: 4월 26일 천왕성 상승궁 진입, 2월 7일 토성 리턴)는 표가 아니라 본문 "• 올해의 전환점" 문단에서 설명한다.

## 7. 5년 타임라인

- 2027→2031 점 5개를 별자리 선처럼 잇는다. 별 크기·밝기 = 이루어짐: 활짝 열리는 해(순풍) = 밝고 큰 별, 내 손에 달린 해(보통) = 중간, 기반을 다지는 해(역풍) = 작은 별(흐리게 지우지 않고 테두리를 또렷이). 각 별 아래 연도 + 판정 이름(두 말 함께) + 한 줄 테마.
- 별 둘레 반짝임 = 움직임: 움직이는 해만 가는 펄골드 고리가 3~4초 주기로 반짝인다('동작 줄이기' 설정 시 점선 고리로 대체). 잔잔한 해는 고리 없음. 반짝임은 좋고 나쁨이 아니라 '바뀌는 정도'라는 범례를 타임라인 아래 한 줄로 둔다: "✦ 고리 = 삶이 크게 움직이는 해".
- '바라는 것이 처음 열리는 해'는 별 안을 pearl-gold로 채운다(반짝임 고리와 구분). 작은 별에도 그 해의 한 줄을 달아 솔직함 원칙을 지킨다.

## 8. 4원소 막대

- 불·흙·공기·물 4줄 가로 막대, navy 계열 명도 차 + 원소 이름·점수 글자 표기. 가장 강한 원소에 pearl-gold 점 하나.
