# SSOL Astro House — Korean → English translation guide (updated 2026-11-04)

Audience: English-speaking users of a gentle astrology-based wellness test.

## Voice (v2, 2026-11-04 — client direction)
- Confident, assured, uplifting. Few hedges (may / might / perhaps / maybe): at most one soft hedge per paragraph, only where a line would otherwise promise health, money, or another person's feelings.
- Active voice with the reader ("you") as subject. Avoid passive and "It is… / There is… / This is a year when…" openers.
- Mix in imperatives where advice is given ("Trust your pace.").
- Elegant, slightly mystical vocabulary is welcome; a genuinely hard or archaic word gets a short gloss in parentheses: "a liminal (in-between) season". Never in buttons, errors or legal text. No slang.
- English horoscope idioms for Korean fortune expressions: 귀인 → "a supportive mentor steps into your life", 운이 트인다 → "doors of opportunity open wide", transits as "Jupiter moves into your 2nd house", "Mercury goes retrograde" (never "in retrograde").
- Product rules still hold: no health/investment predictions, no guarantees, no fear, no **.

Previous voice note (v1): warm, plain, second person, short sentences, no jargon beyond the glossary, no hype. Keep the honesty: hard years are named honestly but kindly. Don't add content; don't drop content. Korean alternates 해요체/합니다체 — in English just vary sentence rhythm.

## Hard rules
- Keep every token exactly as written, in the same braces: `{닉네임}` → `{닉네임}`, `{{근거}}` → `{{근거}}`, `{{열리는해}}` etc. Token NAMES stay Korean (developers map them).
- Josa tokens: `{{X:이/가}}`, `{바람:을/를}`, `{{열리는해:이에요/예요}}` → drop the particle part in English: `{{X}}`, `{바람}`, `{{열리는해}}`. Write the English sentence so the token reads naturally.
- `{닉네임}님` → `{닉네임}` (no honorific). “OO님의” → “{닉네임}'s”.
- Square-bracket buttons stay bracketed: [테스트 하기] → [Start the test].
- Numbers, dates, URLs, emails, emoji (✨🌙) stay as they are.
- No `**`. Use straight quotes ' ' and " " or keep the Korean curly ones as ‘ ’ “ ”.
- If a string is a code fragment or mixed code (e.g. `' + esc(x) + '님의 한 해는 이랬어요`), translate ONLY the Korean parts and keep every code character exactly (quotes, +, esc(), HTML tags). If it is a single Korean word used as a data key (e.g. '어울림', '열리는해', '순풍'), still give the English and add note "data key — keep Korean key in code".
- Markdown lines (from docs): keep the markdown symbols (#, |, -, **, `code`) and table pipes exactly; translate only the Korean text.
