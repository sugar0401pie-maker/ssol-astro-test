## 한눈에 보는 결정

- 흐름(로그인 먼저): 인트로 [테스트 하기] / [내 결과 보기] → 로그인(“빠르게 로그인하고 내 별자리를 확인해볼까요?”, [5초만에 빠르게 카카오로 시작하기]·네이버·이메일, 로그인돼 있으면 건너뜀) → 환영·닉네임 → 경험 확인 → 생년월일·시간·출생지 + 필수 동의 4개(만 14세 이상·개인정보·약관·입력 정보와 결과 저장) → 질문 3개 → 로딩 → 결과(계정에 자동 저장)
- 로그인 없이 테스트하기: 로그인 화면 맨 아래 작은 글씨. 임시 계정 30일 보관, 결제 가능, 쏘웰라 불가, 저장·결제 후·쏘웰라 버튼에서 로그인 권유. 카카오·네이버·이메일은 각각 별도 계정
- 결과 화면: 웹툰식 주제별 페이지 7장(제목 → 주제 그림 4:5 → 굵은 요약 → 본문 → [다음 이야기 ›]), 위쪽 진행 막대, 페이지별 주소(/result/{id}/1~7), 마지막 페이지 기억
- 무료/결제: 1~3장(하늘·유형·2026 회고) 전부 무료(AI 0회). 4~7장(연말·2027·5년·질문)은 굵은 요약 + 첫 두 문장만 공개, 나머지 블러(B13 가짜 문장) + 떠 있는 결제 카드 “여기부터는 결제 후 이어서 읽을 수 있어요 / [1,900원으로 이어서 읽기]”. 결제 후 같은 페이지로 복귀. 4~7장마다 공유·저장(“결제하지 않더라도 지금까지의 결과를 공유할 수 있어요.”)
- 가격: 1,900원 + 쏘웰라 3일 이용권(로그인 계정만). 유료 리포트 GPT-6.1 Sol 3파트 병렬(건당 약 110~120원), 채팅 GPT-6 Luna
- 질문: Q1 고민 영역 6 / Q2 2026 한 단어 10 / Q3 2027 바람 11(‘시작’ 포함)
- 계산: astronomy-engine(MIT), 트로피컬, 홀사인, IANA 시간대(한국 옛 서머타임·해외 서머타임 포함). 모든 숫자·날짜는 서버가 계산하고 AI에는 토큰으로만
- 2026 회고: 단어 × 하늘 주제 첫 문단(A12c) → 올해의 전환점(개인 트랜짓 우선) → 단어 × 고민 영역(A12d) → 마무리. 같은 출생정보면 같은 표현(해시)
- 바람 판정 v3: 이루어짐(활짝 열리는 해(순풍) / 내 손에 달린 해(보통) / 기반을 다지는 해(역풍)) + 움직임(움직이는 해 / 잔잔한 해), 전통 관행(지배 행성·섹트·프로펙션), 판정 문장 칸마다 5개, 바람과 흐름 잇기는 AI 4문장(실패 시 B12)
- 유형: 캐릭터 판정은 계산하되 화면에는 이름·일러스트 없이 유형으로만(show_character=false)
- 원칙: 솔직하되 서버가 정한 근거로 희망, 변화는 기회일 수 있음, 단정·공포·건강/투자 예측 금지, 이론명 화면 비노출, ** 금지
- 디자인: 쏠 남색·크림 + 펄골드, 밤하늘

## 남은 결정·받을 것

- 그림: 결과 주제 그림 7장(art_01~07, 4:5, 1080×1350), 12궁 일러스트 나머지 6장, 화면별 안내 캐릭터 — 준비되는 대로 전달
- 상담사 검수: 해석 DB 1,802행 전부 ‘미검수’
- 법률 검토: 쏘웰라 활용 동의·고지 문구(16_쏘웰라연결), 개인정보 처리방침·약관 반영
- 개발 확인: 기존 디저트 테스트의 결제(토스)·로그인·동의 API와 테이블을 그대로 쓸지(14_DB설계/설명.md)
- 파일럿 후 조정: 판정 기준값(0·4)과 움직임 기준값(1.8·3.2) — 세 판정이 나오는 비율과 사용자 반응을 보고
- 공유 카드(미리보기 제목·설명·태양 별자리별 이미지): 콘텐츠 제작 중

## 개발 순서(요약)

1. 07 엔진을 서버로 옮기고 18_정답비교세트로 자동 테스트(+5명은 Astro-Seek 홀사인으로 눈 확인). 시간 변환은 IANA tzdata(17_해외도시 문서)
2. 14_DB설계로 테이블·행 단위 보안 구성(기존 결제·로그인 API 재사용 여부 먼저 확인)
3. 11_해석DB JSON을 서버에 적재, 무료 1~3장 조립(AI 0회) — 13_프로토타입이 조립 순서의 기준
4. 06 프롬프트 + 15_AI검증으로 유료 4~7장 생성·검증 루프(가상 사용자 10명)
5. 디저트 테스트 Next.js에 로그인 먼저 흐름·웹툰식 결과 페이지·블러 페이월·페이지별 주소 추가(02 디자인)
6. 16_쏘웰라연결로 로그인 계정의 결과 요약을 쏘웰라에 넘기기
7. 30명 파일럿 → 11월 안 출시 목표
