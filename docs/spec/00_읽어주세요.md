## 한눈에 보는 결정

- 흐름: 인트로(디저트 테스트와 동일) → 환영·닉네임 → 점성술 경험 확인 → 생년월일·태어난 시간·태어난 곳(한 화면) → 질문 3개 → 로딩 → 결과(로그인 화면 없음, 결과의 [저장하기] → “저장되었습니다!” → 비로그인이면 로그인)
- 시간 모를 때: 새벽/오전/오후/저녁/잘 모르겠어요. 출생지: 한국 17개 시·도 또는 해외 도시 검색(GeoNames 자체 DB). 양력만.
- 계산: astronomy-engine(MIT) 자체 계산, 트로피컬, 홀사인. 모든 숫자·날짜는 서버가 계산하고 AI에는 토큰으로만 준다.
- 캐릭터: 태양 별자리는 날짜로 표시, 캐릭터는 차트 전체로 판정(가장 긴장받는 행성 = 역량 × 가장 강한 원소 = 방식) → 관계성 테스트 20종.
- 결과: 무료 3섹션(태어난 순간의 하늘·캐릭터·2026 회고, AI 0회) + 유료 4섹션(연말·2027·앞으로 5년·질문과 실천).
- 가격: 1,900원 + 쏘웰라 3일 이용권. 유료 리포트 GPT-6.1 Sol 3파트 병렬, 채팅 GPT-6 Luna.
- 바람 판정(v3): '원하는 방향대로 이루어지는가'를 이루어짐 = 활짝 열리는 해(순풍) / 내 손에 달린 해(보통) / 기반을 다지는 해(역풍)로, 삶이 바뀌는 정도를 움직임 = 움직이는 해 / 잔잔한 해로 따로 보여준다. 전통 점성술 관행(하우스 지배 행성·섹트·연간 프로펙션) 적용, 기질(활동·고정·변통)에 따라 움직임 문장 선택.
- 원칙: 솔직하되 서버가 정한 근거로 희망, 변화는 기회일 수도 있음, 예측 단정·공포·건강/투자 예측 금지, 이론명 화면 비노출, ** 금지.
- 디자인: 쏠 남색·크림 + 펄골드, 밤하늘. 시기별 표는 모바일 2열 + 행마다 접힌 근거(섹션 맨 끝).
