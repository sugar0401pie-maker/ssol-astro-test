# 변경안 — 유형 고르기 두 번째 방식: C 규칙 → D 규칙 (2026-10-12 확정)

바뀌는 것은 **4개 카드의 두 번째 방식을 고르는 규칙**과 **2장 ‘왜 이 유형인가’ 근거 문장 2개 추가**뿐이다. 화면 구성, 카드 문장(B6 choice_line), 화면 안내(A15), 적용 화면 두 곳, 결제 후 잠금은 지금 그대로 둔다.

## 1. 왜 바꾸나

- 지금(C 규칙: 태양 원소 우선)은 강한 원소만 봐서, 두 방식이 둘 다 ‘간직하는 쪽’(맞춰주기·거리두기)으로 나오는 일이 많다. 그러면 카드 4개가 모두 소극적으로 읽힌다(실제 화면 확인: 선 지키기·회복하기 × 맞춰주기·거리두기).
- 모의 계산 4,000건: C 규칙에서 두 방식이 같은 그룹 36%, 둘 다 간직하는 쪽 18%. D 규칙은 0%.

## 2. D 규칙

방식을 두 그룹으로 나눈다.

| 그룹 | 방식(원소) | 카드에서 읽히는 모습 |
| --- | --- | --- |
| 꺼내는 쪽 | 다가가기(불), 조율하기(흙) | 바로 말한다 / 따져 보고 조건을 붙여 말한다 |
| 간직하는 쪽 | 거리두기(공기), 맞춰주기(물) | 물러났다가 나중에 말한다 / 말하지 않고 맞춘다 |

- 첫 번째 방식 = 차트 1등 원소의 방식(지금과 같음)
- 두 번째 방식 = **1등 원소의 반대 그룹 두 원소 중 점수가 더 높은 원소의 방식**
- 반대 그룹 안에서 동점 → 달의 원소 → 태양의 원소 → 정해진 짝
- 반대 그룹 두 원소가 모두 0점(약 2.5%) → 정해진 짝: 거리두기 ↔ 다가가기, 맞춰주기 ↔ 조율하기
- 이 그룹은 고전 점성술의 양·음 구분이 아니라, 이 테스트의 방식 뜻(마음을 말로 꺼내는지)에 따른 구분이다.

```js
const STYLE = { 불: '다가가기', 흙: '조율하기', 공기: '거리두기', 물: '맞춰주기' };
const OPP = { 불: ['공기', '물'], 흙: ['공기', '물'], 공기: ['불', '흙'], 물: ['불', '흙'] };
const PAIR = { 공기: '불', 불: '공기', 물: '흙', 흙: '물' };

function secondElement(score, e1, moonEl, sunEl) {
  const [a, b] = OPP[e1];
  if (score[a] === 0 && score[b] === 0) return { el: PAIR[e1], zero: true };
  if (score[a] !== score[b]) return { el: score[a] > score[b] ? a : b, zero: false };
  for (const e of [moonEl, sunEl]) if (e === a || e === b) return { el: e, zero: false };
  return { el: PAIR[e1], zero: false };
}
```

## 3. 2장 ‘왜 이 유형인가’ 근거 문장 (A5c, 고른 방식이 1등 원소 방식이 아닐 때)

A5 why_text 마지막 문장의 “…것은, 차트에서 ○○의 기운이 가장 강하기 때문입니다.” 자리를 바꾼다. 고르는 순서:

| 순서 | 조건 | ID | 상태 |
| --- | --- | --- | --- |
| 0 | 시간 모름으로 후보끼리 방식이 다름 | STYLE_WHY_TIME | 그대로 |
| 1 | 고른 원소 = 태양 별자리 원소 | STYLE_WHY_SUN | 그대로 |
| 2 | 고른 원소 = 차트 전체 2등 원소 | STYLE_WHY_SECOND | 그대로 |
| 3 | 그 밖(반대 그룹이지만 태양·2등이 아님) | **STYLE_WHY_OTHER** | **새로 추가** |
| 4 | 반대 그룹 0점이라 정해진 짝을 고름 | **STYLE_WHY_ZERO** | **새로 추가** |

새 문장 2개(“…것은, ” 다음에 붙임):

- STYLE_WHY_OTHER: 차트에서 가장 강한 기운은 {{원소1:이지만/지만}}, 함께 자리한 {{고른원소}}의 기운이 마음이 흔들리는 순간에 앞으로 나오기 때문입니다.
  - 예: “…것은, 차트에서 가장 강한 기운은 물이지만, 함께 자리한 흙의 기운이 마음이 흔들리는 순간에 앞으로 나오기 때문입니다.”
- STYLE_WHY_ZERO: 차트에는 {{고른원소}}의 기운이 거의 없지만, 마음이 흔들리는 순간에는 부족한 쪽을 채우려는 마음이 앞으로 나오기 때문입니다.
  - 예: “…것은, 차트에는 불의 기운이 거의 없지만, 마음이 흔들리는 순간에는 부족한 쪽을 채우려는 마음이 앞으로 나오기 때문입니다.”

모의 계산상 두 번째 방식의 근거 문장 비율: SUN 19% · SECOND 46% · OTHER 32% · ZERO 2.5%.

## 4. 예시

- 화면 사례(선 지키기·회복하기, 1등이 거리두기 또는 맞춰주기): 두 번째 방식이 불·흙 중 강한 쪽으로 바뀐다. 불이 강하면 “누가 선을 넘는다 싶으면 그 자리에서 바로 불편하다고 말해요”(선 지키기 × 다가가기), “서먹해지면 그날 안에 먼저 연락해 풀고 싶어져요”(회복하기 × 다가가기). 흙이 강하면 조율하기 카드.
- 치즈케익(1994-08-02 서울, 시간 모름): 공기 5 · 물 4 · 불 3 · 흙 2 → 반대 그룹 불 3 > 흙 2 → 다가가기. 지금 결과와 같다(근거 문장은 태양 원소라 SUN).
