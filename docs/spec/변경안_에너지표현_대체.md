# 변경안 초안 — “~하는 일에 에너지가 많이 들고” 반복 줄이기 (2026-10-12, owner 선택 전)

## 1. 지금 어디서 반복되나 (한 사람의 결과 2장 안에서 세 번)

| 자리 | 출처 | 지금 문장(예: 회복하기 × 다가가기) |
|---|---|---|
| ① 굵은 요약 | 해석 DB A5 `type_line` (20행) | 다툰 뒤 다시 가까워지는 일에 **에너지가 많이 들고**, 그럴 때 먼저 다가가는 유형 |
| ② 웰니스 유형 문단 | 코드(`wellnessTypeLine`) | …관계를 다시 따뜻하게 잇는 갈등 회복의 역량에 **에너지가 많이 드는 편이에요.** |
| ③ 왜 이 유형인가 | 해석 DB A5 `why_text` (20행) | 그래서 다툼 뒤 관계를 다시 잇는 일이 가장 **에너지가 드는 역량이에요.** |

같은 A5 `type_line`은 내 결과 목록·리포트 AI 입력에도 쓰인다.

## 2. 바꿔 쓸 수 있는 표현 (뜻은 같고 부정적이지 않은 것만)

| 표현 | 요약(①) 예시 |
|---|---|
| 마음이 많이 쓰이고 | 다툰 뒤 다시 가까워지는 일에 마음이 많이 쓰이고, 그럴 때 먼저 다가가는 유형 |
| 힘이 많이 들어가고 | 누군가에게 기대는 일에 힘이 많이 들어가고, 그럴 때 먼저 다가가는 유형 |
| 신경이 많이 쓰이고 | 내 선을 지키는 일에 신경이 많이 쓰이고, 그럴 때 먼저 다가가는 유형 |
| 품이 많이 들고 | 마음을 말로 꺼내는 일에 품이 많이 들고, 그럴 때 먼저 다가가는 유형 |
| 마음을 많이 기울이게 되고 | 관계를 믿고 마음을 놓는 일에 마음을 많이 기울이게 되고, 그럴 때 먼저 다가가는 유형 |

쓰지 않는 게 좋은 표현: ‘쉽게 지치고’, ‘어렵고’, ‘서툴고’ — 약점·결핍으로 읽혀 진단처럼 들릴 수 있다.

## 3. 추천 배치 (한 화면 안에서 겹치지 않게)

- ① 요약(A5 type_line, 20행): **“~하는 일에 마음이 많이 쓰이고, 그럴 때 ~하는 유형”** 으로 통일
- ② 웰니스 유형 문단(코드): **“~에 힘이 많이 들어가는 편이에요.”** — 코드라 owner 확인 후 바로 바꿀 수 있음
- ③ 왜 이 유형인가(A5 why_text, 20행): **“가장 마음을 많이 쓰는 역량이에요.”** (“가장 에너지가 드는 역량이 돼요/이에요” 자리)

→ 세 자리가 ‘마음이 많이 쓰이고 / 힘이 많이 들어가는 / 마음을 많이 쓰는’으로 갈려 같은 말이 반복되지 않는다. ①과 ③이 ‘마음’을 공유하는 게 싫으면 ③을 “가장 품이 많이 드는 역량이에요”로.

다른 방법: ①을 역량별로 다르게(기대기 ‘마음이 많이 쓰이고’, 믿기 ‘마음을 많이 기울이게 되고’, 선 지키기 ‘신경이 많이 쓰이고’, 말하기 ‘품이 많이 들고’, 회복하기 ‘힘이 많이 들어가고’) — 결과를 여러 개 보는 사람(내 결과 목록)에게도 덜 반복된다.

## 4. 반영 방법

- ①·③은 해석 DB 문장이라 엑셀 A5 시트(type_line 20행, why_text 20행)에서 고친 뒤 JSON을 보내 주면 교체한다.
- ②는 코드라 owner가 표현을 고르면 바로 고친다.
- 위 예시 문장은 C1 금지어 검사를 통과했다.
