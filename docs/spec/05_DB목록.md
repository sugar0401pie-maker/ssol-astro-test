# 미리 만들어 둘 데이터베이스 (AI 의존 줄이기) v2

원칙: **계산은 엔진, 문장은 DB, AI는 잇기만.** 무료 결과는 100% DB 문장으로 만들고, 유료 리포트도 DB 문장을 뼈대로 쓴다. AI는 조각 사이 연결문과 사용자 3개 답(Q1~Q3)에 맞춘 2~3문장 정도만 쓴다.
장점: 상담사가 모든 문장을 미리 검수할 수 있고, 같은 차트면 같은 해석이 나오며(일관성), 비용·대기 시간이 줄어든다.

## C. 데이터(문장 아님) — 엔진이 쓰는 표

- 한국 17개 시·도 대표 좌표, GeoNames 도시 목록(해외)
- 시간대 5구간 정의, 정확도 등급 규칙
- 이벤트 점수 가중치(행성·대상·각도), 역량 백분위 보정표(모의 출생 3,000건)
- 캐릭터 매핑표(역량 × 방식 → 20종), 원소 → 방식 매핑
- 금지어·검증 규칙(validate)

## D. AI가 맡는 부분 (남는 것)

| 위치 | AI가 하는 일 | DB가 주는 재료 |
| --- | --- | --- |
| 연말 파트 | 이벤트 문장 2~3개를 Q1 고민에 맞춰 한 문단으로 잇기 | A8·A10·A14 |
| 2027 파트 | Q3 판정 문장 + 목성·토성 하우스 문장을 자연스럽게 연결 | A9·A13 |

| 별이 주는 질문 3개 | 캐릭터·Q1에 맞춘 성찰 질문 (또는 DB 질문 은행 60개 중 선택으로 대체 가능) | A5·A14 |

→ 무료 결과는 AI 호출 0회. 유료 리포트도 AI가 쓰는 분량이 전체의 20~30%로 줄어 GPT-6.1 Sol 비용·대기 시간이 함께 준다.
